# Estratégia de Testes

## Objetivo

Validar o funcionamento da API REST ServeRest, garantindo o correto funcionamento dos endpoints disponíveis.

## Escopo

Serão testados:

- Autenticação
- Usuários
- Produtos
- Carrinho

Não serão testados:

- Interface gráfica
- Testes de carga
- Testes de segurança

## Tipos de testes

- Testes funcionais
- Testes negativos
- Testes de integração
- Testes de autorização
